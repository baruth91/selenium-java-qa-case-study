# Contributing

Keep code and learning material in English. Explain the risk, oracle and data
precondition for new scenarios. Use synthetic records and the local demo only.
Run the six-case baseline before adding coverage; then run the focused change
and the relevant regression suite. Include actual validation and remaining limits.

Avoid fixed sleeps, automatic retries, hidden assertion failures, shared driver
sessions and machine-specific executable paths. Attribute external application
and build tooling honestly. Add Grid, more browsers or concurrency only when
their learning objective and isolation requirements are defined.
